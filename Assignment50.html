Student Task Manager

1. Project Idea

Student Task Manager is a simple web application that helps students organize their daily tasks, assignments and study activities.

2. Project Aim

The main aim of this project is to improve student productivity by providing an easy way to manage and track daily tasks.

3. Core Features

  • Add new tasks.
  • Edit existing tasks.
  • Delete tasks.
  • Mark tasks as completed.
  • Filter pending and completed tasks.
  • Save tasks using localStorage.
  • Responsive user interface.

4. User Requirements

  • Users should be able to add tasks easily.
  • Users should be able to update task details.
  • Users should be able to delete unwanted tasks.
  • Tasks should remain saved after refreshing the page.
  • The application should be easy to use.

5. Technologies Used

  • HTML - Webpage Structure
  • CSS - Styling and Layout
  • JavaScript - Functionality
  • localStorage - Data Persistence

6. Expected Outcome

A functional and user-friendly Student Task Manager that helps students manage their academic activities efficiently.
